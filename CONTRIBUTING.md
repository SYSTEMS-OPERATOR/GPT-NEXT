# Contributing to GPT-NEXT

Thank you for taking the time to contribute! The following guidelines will help ensure a smooth development process.

## Getting Started
1. Fork the repository and create your branch from `main`.
2. If you've added code, make sure to add tests when possible.
3. Run the provided linters and unit tests before submitting a pull request.

## Pull Request Process
1. Ensure your PR has a clear description of the changes.
2. Update documentation as needed.
3. Make sure all tests pass.

## Code Style
We follow [PEP8](https://peps.python.org/pep-0008/) guidelines for Python code. Use descriptive variable names and add docstrings for new functions and classes.

## Reporting Issues
Open an issue describing the problem with steps to reproduce. Include relevant logs or screenshots when applicable.

We appreciate your contributions!
